# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for suspected vulnerabilities in RepoSafe itself. Send a private report to the project maintainer with:

- affected version or commit
- reproduction steps
- expected impact
- suggested fix, if available

The maintainer should acknowledge the report, validate impact, prepare a fix, and publish a short advisory after release.

## Scope

RepoSafe is a local static scanner. It does not upload scanned repository contents and does not require network access for the core checks.
